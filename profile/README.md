## How it works

- **Non-custodial.** Every action is a transaction you review and sign in your own wallet. Tokenry never holds your keys, tokens or funds.
- **Checked before you sign.** The Solana tools and the EVM liquidity tools simulate your transaction against the current chain state before your wallet asks you to sign.
- **Clear fees.** Each tool's fee is shown in the chain's own coin on the review screen, before anything is signed. See [all fees](https://tokenry.tools/fees).
- **Readable token source.** After an EVM token deploys, Tokenry submits its source for verification on the chain's main explorer, so holders can read it. See [security](https://tokenry.tools/security).
